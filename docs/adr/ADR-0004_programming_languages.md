# ADR-0004: Programming Languages and Frameworks

## Context

Developing meshwatch requires programming languages.

We need to choose technologies for device simulation,
backend development, and the web interface.

We considered Python, JavaScript, C++. HTML and CSS for development.

## Decision

First we will use the following technologies:

- Python for simulating IoT devices and backend development.
- JavaScript for interactive web functionality.
- HTML for the structure of the web interface.
- CSS for styling the web interface.
this section may be adopted on later stages. 

## Status

Accepted.

## Consequences

These programming languages are widely used and provide
good support for web and IoT applications.

Python allows us to simulate devices without
physical hardware, while JavaScript, HTML, and CSS
allow us to build an interactive web interface.

However, using multiple technologies requires
knowledge of both backend and frontend development.
